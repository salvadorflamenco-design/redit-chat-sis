La llave de acceso (ANTHROPIC_API_KEY) se coloca solo en el servidor, en el archivo chat-sis/.env. Nunca se escribe en el navegador ni en esta pantalla; aquí solo se indica si existe o no.

Variables disponibles en ese mismo archivo:

  • MODERACION_IA_MODO: apagado, previo o posterior.
  • MODERACION_IA_MODELO: modelo inicial. Si eliges uno en esta pantalla, ese tiene prioridad y no requiere reiniciar.
  • MODERACION_IA_TIMEOUT_MS: tiempo máximo de espera por respuesta, en milisegundos.
  • MODERACION_BLOQUEAR_DESDE: severidad a partir de la cual un mensaje se bloquea.

Después de cambiar el archivo, reinicia el servidor con docker compose up -d chat-sis-backend.

Si la IA falla o no está disponible, el chat sigue funcionando con el diccionario de palabras. Tras 3 fallos seguidos la IA se pausa 60 segundos y luego vuelve a intentarlo automáticamente.

El MCP (mcp/moderacion-server.js) es algo aparte: sirve para que un agente (por ejemplo Claude Code) revise mensajes ya publicados. Las instrucciones están en mcp/README.md.

Nombre legible que se mostrará en las alertas

El puntaje de un mensaje suma el peso de todas las coincidencias (y aumenta si el insulto va dirigido a alguien, por ejemplo «eres un...»). La severidad de la alerta sigue al peso: Grave genera alerta alta, Moderado genera media y Leve genera baja. Sube de nivel si el insulto va dirigido (al menos media) o si el puntaje acumulado llega a 3 (media) o a 6 (alta). Usa Leve para palabras malsonantes comunes, Moderado para insultos y Grave para amenazas u ofensas serias.
